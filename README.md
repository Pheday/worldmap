# Страны мира — тест по карте

Откройте `index.html` двойным кликом. Сервер и интернет не нужны.

Режимы: страны, столицы, флаги. При клике по стране (по ошибке, по уже отгаданной или после игры) показывается карточка: флаг, герб, столица, население, площадь, ВВП по ППС на душу населения (с местом в рейтинге), валюта, языки. Какие поля показывать, выбирается в настройках (⚙), звук включается кнопкой в шапке; выбор запоминается в браузере. Герб по умолчанию выключен.

## Состав файлов

- `index.html`, `style.css`, `app.js` — страница.
- `data/data.js` — контуры стран и сведения о них (собирается скриптами).
- `data/flags`, `data/arms` — флаги и гербы.
- `tools/` — скрипты сборки данных (нужен Node.js).

## Пересборка данных

```
cd tools
npm install
node fetch-admin1.mjs   # один раз: границы областей для сборки карты → tools/cache
node build-map.mjs      # контуры из tools/cache/ne_10m_admin_0_countries_rus.geojson
node fetch-data.mjs     # Wikidata и Всемирный банк → tools/cache
node build-data.mjs     # сведение + ручные правки из overrides.mjs, печатает таблицу для проверки
node fetch-images.mjs   # флаги и гербы (уже скачанные пропускаются)
node build-js.mjs       # итоговый data/data.js
```

Названия, столицы, валюты и языки правятся в `tools/overrides.mjs`, после чего запускаются `build-data.mjs` и `build-js.mjs`.

## Источники

- Карта: Natural Earth 1:10m, вариант «с точки зрения России» (Крым — Россия; Абхазия и Южная Осетия отдельно), Карабах — к Азербайджану, как на motovskikh.ru.
- ДНР, ЛНР, Запорожская и Херсонская области показаны в составе России — по конституции России, в границах соответствующих областей. Границы взяты из Natural Earth 1:10m admin-1 (`ne_10m_admin_1_states_provinces.geojson`, скачивается `fetch-admin1.mjs`): области вырезаны из контура Украины и добавлены России по общему контуру, поэтому на стыке нет щелей и наложений. Список областей — `CLAIMS` в `tools/build-map.mjs`.
- Состав стран (199) — как на motovskikh.ru: члены ООН, Ватикан, Палестина, Западная Сахара, Абхазия, Южная Осетия, Антарктида.
- ВВП по ППС на душу населения — Всемирный банк (NY.GDP.PCAP.PP.CD, текущие международные доллары), год, за который есть данные почти по всем странам; если по стране за этот год данных нет — её последний год (указан в карточке). Место считается среди стран, по которым есть данные; нет данных по КНДР, Кубе, Венесуэле, Йемену, Эритрее, Лихтенштейну, Монако, Ватикану, Абхазии, Южной Осетии и Западной Сахаре.
- Население и площадь — Всемирный банк; для стран, которых там нет, — Wikidata (год указан в карточке). Границы на карте и цифры в карточке могут расходиться: площадь и население даны по данным Всемирного банка, без пересчёта на показанные границы (так же было и с Крымом).
- Названия, столицы, валюты, языки, флаги, гербы — Wikidata и Wikimedia Commons.
