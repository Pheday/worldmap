# Страны мира — тест по карте

Откройте `index.html` двойным кликом. Сервер и интернет не нужны.

Режимы: страны, столицы, флаги. При клике по стране (по ошибке, по уже отгаданной или после игры) показывается карточка: флаг, герб, столица, население, площадь, валюта, языки. Какие поля показывать и включён ли звук, выбирается в настройках (⚙); выбор запоминается в браузере. Герб по умолчанию выключен.

## Состав файлов

- `index.html`, `style.css`, `app.js` — страница.
- `data/data.js` — контуры стран и сведения о них (собирается скриптами).
- `data/flags`, `data/arms` — флаги и гербы.
- `tools/` — скрипты сборки данных (нужен Node.js).

## Пересборка данных

```
cd tools
npm install
node build-map.mjs      # контуры из tools/cache/ne_10m_admin_0_countries_rus.geojson
node fetch-data.mjs     # Wikidata и Всемирный банк → tools/cache
node build-data.mjs     # сведение + ручные правки из overrides.mjs, печатает таблицу для проверки
node fetch-images.mjs   # флаги и гербы (уже скачанные пропускаются)
node build-js.mjs       # итоговый data/data.js
```

Названия, столицы, валюты и языки правятся в `tools/overrides.mjs`, после чего запускаются `build-data.mjs` и `build-js.mjs`.

## Источники

- Карта: Natural Earth 1:10m, вариант «с точки зрения России» (Крым — Россия; Абхазия и Южная Осетия отдельно). Донецкая и Луганская области присоединены к Украине, Карабах — к Азербайджану, как на motovskikh.ru.
- Состав стран (199) — как на motovskikh.ru: члены ООН, Ватикан, Палестина, Западная Сахара, Абхазия, Южная Осетия, Антарктида.
- Население и площадь — Всемирный банк; для стран, которых там нет, — Wikidata (год указан в карточке).
- Названия, столицы, валюты, языки, флаги, гербы — Wikidata и Wikimedia Commons.
