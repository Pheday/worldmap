# Страны мира — тест по карте

Офлайн-страница: `index.html` открывается с диска (file://), без сервера и сборщика. Поэтому данные лежат в `data/data.js` (`window.QUIZ_DATA = …`), а не в JSON, и внешних зависимостей у страницы нет. Подробности для людей — в README.md.

## Где что

- `app.js` — вся логика страницы (один IIFE, разделы помечены `/* ---------- … ---------- */`): настройки, языки, звуки, карта, масштаб, подсказка, карточка страны и особой территории (`showCard`, `showTerritoryCard`, `factRows`), игра, кнопки.
- `i18n.js` — тексты интерфейса на ru/en/zh. Любая новая строка интерфейса добавляется во все три языка.
- `style.css`, `index.html` — разметка и стили. В `index.html` у ссылок на `style.css`, `app.js`, `i18n.js`, `data/data.js` стоит `?v=N`: GitHub Pages кэширует файлы на 10 минут, поэтому после правки любого из них N увеличивается (у всех сразу), иначе телефон показывает старую версию.
- `data/data.js` — генерируется `tools/build-js.mjs`, руками не править. `data/flags`, `data/arms` — PNG, качает `fetch-images.mjs`.
- `tools/` — сборка данных (Node.js, ESM `.mjs`). `tools/cache/` в .gitignore: там промежуточные JSON и исходники Natural Earth.

## Сборка данных

Порядок (из `tools/`): `build-map` → `fetch-data` → `fetch-i18n` → `fetch-territories` → `build-data` → `fetch-links` → `fetch-images` → `build-js`. Скрипты `fetch-*` ходят в Wikidata, Всемирный банк, Википедию, Commons. Без нужды их не перезапускать, кэш уже лежит в `tools/cache`; после ручных правок хватает `build-data` (+ `fetch-links`, если менялись столицы или валюты) и `build-js`.

- Ручные правки стран и территорий — `tools/overrides.mjs` (NAME, CAPITAL, CURRENCY, LANGUAGE, *_I18N, WIKI_TITLE, FLAG_FILE/ARMS_FILE). Коды территорий не пересекаются с кодами стран, таблицы общие.
- Особые территории — `tools/territories.mjs` (статус, владелец, претенденты, статья Рувики, `qid`, `uninhabited`). `build-js` падает, если у серой территории на карте нет записи.
- Островные государства с обводкой вместо кружка — `ARCHIPELAGOS` в `build-js.mjs`; аннексированные области — `CLAIMS` в `build-map.mjs`.
- `build-data.mjs` печатает таблицу по всем странам и территориям и строку «НЕТ ПЕРЕВОДА» — после правок смотреть её.

## Проверка

`cd tools && node test-ui.mjs <папка>` — Puppeteer с локальным Chrome (`C:/Program Files/Google/Chrome/Application/chrome.exe`), прогоняет сценарии, печатает содержимое карточек и сохраняет скриншоты. Папку для скриншотов нужно создать заранее; в конце должно быть «ошибки в консоли: нет». Скриншоты смотреть глазами при любых правках вида.

## Соглашения

- Комментарии в коде и README — по-русски; сообщения коммитов — по-английски.
- Ссылки на статьи ведут в Рувики (`ru.ruwiki.ru`), заголовки сверяются с русской Википедией: Рувики закрыт для автоматических запросов.
- Масштабы в `app.js` считаются в единицах карты и пикселях экрана; на узких экранах (телефон) поведение проверять отдельно.
- Границы и состав стран — как на motovskikh.ru (см. README, «Источники»); не менять без явной просьбы.
